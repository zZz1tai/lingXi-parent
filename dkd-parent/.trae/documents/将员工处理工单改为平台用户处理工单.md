# 1. 数据表设计

## 1.1 现有表结构分析
- `tb_task`：工单表，当前使用 `user_id` 关联员工表 `tb_emp`
- `tb_emp`：员工表，存储员工信息
- `sys_user`：系统用户表，存储平台登录用户信息

## 1.2 新表设计
创建新表 `tb_user_task_relation` 来关联系统用户和工单：

```sql
CREATE TABLE `tb_user_task_relation` (
    `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `user_id` bigint NOT NULL COMMENT '系统用户ID',
    `task_id` bigint NOT NULL COMMENT '工单ID',
    `relation_type` int NOT NULL DEFAULT 0 COMMENT '关联类型：0-执行人 1-指派人',
    `create_time` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_task_type` (`user_id`, `task_id`, `relation_type`),
    KEY `idx_task_id` (`task_id`),
    CONSTRAINT `fk_user_task_relation_user` FOREIGN KEY (`user_id`) REFERENCES `sys_user` (`user_id`) ON DELETE CASCADE,
    CONSTRAINT `fk_user_task_relation_task` FOREIGN KEY (`task_id`) REFERENCES `tb_task` (`task_id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户工单关联表';
```
